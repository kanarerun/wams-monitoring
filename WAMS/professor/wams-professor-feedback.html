Tips for a good report
  • 1 Choose the right type — Bug for something broken, Feature Request for something missing, Performance if the system is slow or unresponsive.
  • 2 Be specific in the subject. "Create Exam button not saving" is more actionable than "Exam page broken."
  • 3 For bugs, include steps to reproduce the issue so the admin can replicate it.
  • 4 Attach a screenshot if the issue has a visible symptom — it speeds up the fix significantly.
  • 5 Leave your email so the admin can follow up. Most issues are resolved faster with a short back-and-forth.
