# WAMS — Web-based Academic Monitoring System

Web-based platform for managing examinations with proctoring capabilities. Supports three portals: **Admin**, **Professor**, and **Student**.

---

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) **v18 or higher** (includes `npm`)

### 1. Install dependencies

```bash
npm run install:all
```
*(or `npm install --prefix server`)*

### 2. Start the server

```bash
npm start
```

Or run directly:
```bash
node server/index.js
```

### 3. Open the app

Browse to **http://localhost:3000** and select your portal.

| Portal | URL | Credentials / Login Flow |
|--------|-----|--------------------------|
| Landing | `http://localhost:3000/` | Entry point to all portals |
| Admin | `http://localhost:3000/WAMS/admin/wams-admin-log-in.html` | Username: `admin` · Password: `admin123` |

| Student | `http://localhost:3000/WAMS/student/wams-student-log-in.html` | Student ID & active Exam Access Code |

- **Admin**: Manage instructors, students, course sections, feedbacks, system health diagnostics, and view real-time metrics.
- **Professor**: Create exams (WAMS Quiz or Google Forms), monitor active sessions with live camera, screen, and audio feeds, review post-exam student logs, and export PDF incident reports.
- **Student**: Take examinations within a proctored environment with built-in calculator and sketchpad utilities.

## 🤖 AI-Assisted Automated Proctoring

- **AI Multi-Face Tracking**: Computer vision morphology and YCbCr skin clustering detect multiple faces, overlaying AI facial hitboxes (Eyes `EYE-L`/`EYE-R`, Nose reticle, Mouth bounding box) and logging evidence automatically.
- **Multi-Voice & Speech Detection**: Web Audio API FFT frequency analysis across fundamental and harmonic formant vocal bands ($100\text{ Hz} - 3400\text{ Hz}$) triggers recording and alerts only upon active conversational speech or multiple voices.
- **Continuous Background Screen Capture**: Prompts students for screen sharing on test entry, capturing periodic high-resolution snapshots directly to the proctoring stream.
- **Tab Switch Detection**: Automatically tracks window blurs, tab switching, and visibility changes with exact timestamps.

## 🌐 Portability / Offline Support

This project is designed to be portable and work offline:

- **All CDN libraries are vendored locally** under `WAMS/vendor/` — Chart.js and jsPDF work without internet.
- **Relative paths used throughout** — works when hosted in a sub-directory (e.g., behind a reverse proxy), not just at the domain root.
- **Single-file SQLite database** — no external database server required.
- **No build step** — plain HTML/CSS/JS served directly by Express.

### Portability features implemented:
1. ✅ Vendored `Chart.js` → `WAMS/vendor/chart.umd.min.js`
2. ✅ Vendored `jsPDF` → `WAMS/vendor/jspdf.umd.min.js`
3. ✅ Converted absolute paths (`/WAMS/...`) to relative paths in `index.html`
4. ✅ Root `package.json` with `npm start` for one-command startup
5. ✅ `.gitignore` to keep the repo clean
6. ✅ README with setup instructions
7. ✅ **Auth guards on all protected pages** — refreshing or navigating directly to any dashboard, management, monitoring, or exam page without a valid session redirects to the appropriate login page
8. ✅ **401 handling** — expired/invalid tokens are cleared and the user is redirected to login instead of showing broken/empty pages
9. ✅ **Consistent logout** — all pages clear both `token` and `wamsToken` on sign-out
10. ✅ **Student session guard** — exam tools require an active student session and redirect to student login otherwise
